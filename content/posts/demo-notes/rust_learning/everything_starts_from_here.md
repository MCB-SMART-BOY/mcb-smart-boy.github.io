学习 *Rust* 这件事情 对于新手而言是学习一门语言

而对于一些已经有编程语法基础的人来说 更多是学习新的思想和表达方式

那么提到编程语言 那离不开的就是编译器和解释器了吧

在这里 *Rust* 是静态语言 自然使用的就是所谓的编译器了

对于一些语言比如大蟒蛇 *Python* 我个人来说并不喜欢使用一个没有任何向后兼容的系统级的解释器（编译器） 所以我使用的时候都会使用一个叫做 *uv* 或者另一个 *pixi* 作为工具链管理器和包管理器

如果你不了解工具链和包管理是什么 不要紧 你现在要知道的事实就是 现代化的工作流中必然会使用他们 所以某些没有官方包管理方式和工具链的编程语言将会受到我们的猛烈抨击（说的就是你cpp和c）

一切编程语言的学习都离不开环境的配置 而作为一个现代化的编程语言 *Rust* 官方给我们提供了非常好用的工具链

接下来就开始我们的配置操作吧
## 环境配置
### 1. 首先是打开你的终端 不管是什么操作系统都有相应的终端 用终端安装 *rustup* 这个软件
  * 如果你是Windows用户 请打开官网 按照官网上去下载 *rustup* 至于怎么打开官网 官网是什么请自行查询 如果没有这个检索能力的人不适合搞技术
  * 如果你是一个linux发行版用户 那请使用对应的系统包管理器来安装
  * 如果你是 mac 用户 那我想你应该知道什么是 *homebrew* 如果不知道的话也不建议你学习任何和技术相关的东西
### 2. 接下来内容对于类Unix和Windows不太一样
  * 对于Windows用户 请按照上面的要求去做 会出什么问题几乎都是Windows的问题 如果出了问题解决不掉请使用 *wsl* 这款工具 什么？你不知道这是什么？那请自行查询 该内容超过了本章的教学范围 并且使用 *wsl* 之后请按照linux用户的方法重来
  * 对于类Unix用户 大多是MacOS和linux发行版（比如arch, nixos, fedora, debian） 接下来的步骤挺适合你们
    1. 安装stable版本的rust工具链（你也不想体验新功能之后回不去了吧）:
    ```shell并且管你什么shell都能用放心哈
      rustup toolchain install stable
    ```
    然后 *rustup* 会自动帮你完成整个stable工具链的安装

    2. 但是刚刚的安装中不包括一个叫做 *rust-analyzer* 的东西 这东西将会为接下来 *Rust* 的编写带来语法高亮 自动补全 等高级功能 所以我们要额外安装:
    ```shell
      rustup component add rust-analyzer
    ```

    3. OK了 就没了 坐等装好就行（斜眼笑） 很明显这并没有什么难点 如果有什么疑问请怀疑自己
    （骗你的 虽然话也可以这么说 但是违反了我们良好的公序良俗和社会主义核心价值观）
    我默认你们已经装好了 那就可以开始 *Rust* 之旅了——才怪
    先验证一下自己的 *Rust* 编译器是否能用:
    ```shell
      # ps: 我知道你们这群用类Unix的喜欢用短参数 还给你们准备了这个：rustc -V
      rustc --version
      # 其实刚刚你们应该也看到了 *rustup* 也装了别的工具
      # 那接下来也验证一下其中一个具有代表性的工具是否能用吧:
      cargo --version
    ```

    4. 确认无误之后就好办了 接下来要创建我们第一个 *Rust* 项目了 选择一个合适的文件夹（我一般选 ~/Projects/ 作为我创建项目的文件夹） 然后使用cargo（你现在只需要知道这是一个包管理器 至于什么作用后面会讲 至少现在这只是个用来创建和运行项目的工具）:
    ```shell
      cargo new rfs # Rust From Scratch for short ~
    ```

  到这里 你成功使用 *Rust* 的工具链创建了一个叫叫做 rsl 的 *Rust* 项目 并且接下来的课程内容都是基于这个项目来讲解的 请做好准备
